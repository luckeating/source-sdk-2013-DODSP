// DOD-SP vehicle types - one block per kind of vehicle. Goes in DOD-SP\scripts\dodsp_vehicles.txt (the game build ships it:
// game_hl2_win32_Release unzips into DOD-SP with bin\ and scripts\ - always take both from one build).
// A dodsp_vehicle in Hammer names one of these with its "vehicletype" key.
//
// Size comes from the model (never typed here). Speeds in units/s (1 unit ~ 1 inch: 39 units/s = 1 m/s),
// accel/brake in units/s^2, turn_rate in degrees/s.
//   forward_yaw      which way the model faces IN GAME (0 = +X). Every CoD2/CoD1 vehicle faces +X in game: their
//                    meshes face -Y, but studiomdl's default 90-degree root rotation turns them (check: the MDL's hull
//                    box is long along X). The game warns if a model is longer sideways than front-to-back.
//   tracked 1        pivots on the spot; 0 = turns like a car (min_turn_radius)
//   turret_offset    where the turret model sits on the hull, model space as in game (x along - front is +x,
//                    y sideways - +y is the vehicle's left, z up).
//                    V3e: CoD2's own tag_turret x 1.028 (exact: every turret model's origin sits on it; the first
//                    values were estimates, off by up to 20 units). The lint checks them against
//                    dodsp_tools/generated/cod2_vehicle_tags.txt. dodsp_vehicle_turret x y z still prints a line.
//   seats            riders (stage V3), model space, yaw relative to the vehicle's front (+90 = facing its left).
//                    "fidget" (V3e, optional): a sequence he plays ONCE now and then while seated (8-20 s apart),
//                    then back to his idle - the tanks use CoD2's lean-and-look (ww2_ride1_idle).
//                    Each seat: "origin", "yaw", "idle" (looping sequence while he rides) and "getout" (the dismount),
//                    both from npc_ww2_anims_ride.mdl, and "delay" (seconds after the order before this man goes).
//                    MEASURED against the meshes and PREVIEWED (dodsp_tools/vehicle_preview/rider_preview.py reads these
//                    lines; the owner approved the tank and carrier previews 2026-11-20): tank riders sit on the deck
//                    edges facing out, legs over the tracks, and jump off outward; carrier riders sit on the side walls
//                    and vault over. Seated idle on every tank seat: ww2_ride3_idle (CoD's tankride guy3 driving idle,
//                    3.8 s, a calm sway). NOT ride1 (guy1 "leanleft" = a lean-out-and-look one-shot, head moves 9 units,
//                    hand 17 - looped it looked like a tantrum, owner 2026-11-20) and NOT ride6 (a 1.2 s engine-rumble
//                    jiggle). The getout's path (where his origin goes, frame by frame) is
//                    scripts/dodsp_ride_paths.txt, written with the ride pack by build_ww2_pack.py --ride-paths.
//                    Halftrack: benches z 40 at |y| 10..24 (x -100..-12), aisle z 30 - its 8 riders get out through the
//                    rear doors, which the model has closed on its only bone; they wait for a door rig.
//   base             another type this one copies everything from; its own keys (and whole blocks) win. The
//                    paint variants (winter, desert, brush, snow) are only their models - one owner per number.
//   faction          axis or allies (who it shoots; a dodsp_vehicle's own "faction" key wins - captured tanks)
//   turret_rate      degrees/s the turret traverses; pitch_rate: degrees/s the barrel elevates
//   gun              main gun (V4, REAL numbers - owner 2026-11-20 "fully real"):
//                      magazine / cyclic   autocannons: rounds per magazine and rounds/minute within it
//                      reload              seconds to load the next round (magazine guns: to change magazines)
//                      rounds              carried (0 = never runs out); range (units), spread (degrees), sound
//                      ap { calibre mm, pen "metres mm ...", effect, filler kg }   fired at vehicles
//                      he { calibre mm, filler kg }                                fired at everything else
//                    pen = penetration of a FLAT (vertical) plate by range - sources quoted against a 30-degree plate
//                    are x 1.155 (1/cos 30). effect = what gets inside when it penetrates (game value, against the
//                    target's "structure"). HE: blast and penetration come from the filler (dodsp_vehicle_armour.h:
//                    75 mm M48 0.68 kg kills ~10 m / wounds ~25 m real; x dodsp_vehicle_he_scale 0.5 against people).
//                    `dodsp_vehicle_penchart` in the console prints who gets through what, where.
//   armour           V4, mm per plate, "thickness [lean]" (lean = degrees back from upright: the Sherman's glacis
//                    "51 56" is 91 mm effective head-on). hull_front/side/rear/top required, hull_bottom = top if
//                    missing; turret_* for turreted types. open_top 1 = open crew compartment. structure = how much
//                    inside effect it takes before it's knocked out (game value, roughly by size). crew = the seats
//                    in order (commander gunner loader driver radio). ammo_fire / fuel_fire = chance an ammunition /
//                    engine hit sets it burning (Sherman dry stowage: 60-80% of penetrated tanks burned - real).
//                    engine rear / front / middle.
//   display          its name in Hammer (the FGD is generated from this file: dodsp_tools/gen_vehicle_fgd.py)
//   dead_model       the wreck (its own paint, so every variant names its own)
//   hatches          V4e: where each crew role gets out when they bail: "turret x y z" (turret model space - it turns
//                    with the turret) or "hull x y z" (hull model space), the roof his feet end up on. MEASURED from the
//                    meshes (2026-11-20, top-down height maps): turret cupolas / hatch rings, hull hatches in front of
//                    the turret, rim height for open compartments. Roles at the same point share the hatch and come
//                    out one after the other. A crew role without one gets out beside the vehicle (the load warns).
//   1 m = 40 units (a 72-unit player ~ 1.8 m). "est." below = not found in a source, an estimate - correct freely.
//   mgs              V3e: the machine guns, each on its REAL mount, fires bursts at infantry. Positions from CoD2's own
//                    tags (dodsp_tools/generated/cod2_vehicle_tags.txt: the MG tag + the MG model's 19-unit flash, x 1.028)
//                    unless marked otherwise. Per gun (any name): "mount" turret = turret model space, turns with it;
//                    barrel = also rises with the gun, turned about "pivot" (tag_barrel); hull = hull model space, a ball
//                    mount that aims on its own within "arc" degrees each side and "pitch" min..max, manned by "crew"
//                    (a crew role). "muzzle" = where the bullets start (at yaw / elevation 0). Then: damage per bullet,
//                    rate (shots/s), burst / pause (seconds), range, spread (degrees), sound (DoD:S's own MG sounds).
//                    (Before V3e one "coax" block fired from the main gun's muzzle - the game warns if it finds one.)
//   sounds           engine_idle / engine_move (looped; idle fades into move with speed), turret_turn (loop) /
//                    turret_stop, reload, explode (shell impact). Entries: scripts/game_sounds_dodsp_vehicles.txt.
//                    Which engine sound fits which vehicle is a GUESS (engine1 light, 2 medium, 3 heavy, truck for
//                    wheels) - swap them by ear.
//   susp_accel       the lurch: degrees the hull pitches per 100 units/s^2 of acceleration (default tracked 1.6,
//                    wheeled 1.0); susp_freq (Hz, 1.6) / susp_damp (0..1, 0.35) its spring; recoil: degrees the main gun
//                    kicks the hull (2). The models have no lurch animation (only 'idle' / turret 'aim') - it's code.
//                    H1: a model whose "dodsp_wheels" gives a body_pivot (the rigged halftrack) rides its BODY on these
//                    springs over wheels that stay on the ground (client, every frame) instead of tipping whole;
//                    susp_roll (degrees outward per 100 units/s^2 sideways, 1.0) applies to those only. How far each
//                    wheel / suspension unit travels is the MODEL's (vehicle_rig.py measures it into "dodsp_wheels"),
//                    never a key here.
//   Halftracks and the carrier have no weapons yet (their MG mounts are V2b).
//   turret_offset    (V3e) = CoD2's tag_turret x 1.028 - exact (the turret models' origins sit on it); the lint checks it.
// Sources (2026-11-20): Wikipedia (Panzer II, 2 cm KwK 30, Tiger I, 8.8 cm KwK 36, M4 Sherman, Crusader tank, Ordnance QF
// 6-pounder, Sd.Kfz. 222, Sd.Kfz. 251, Universal Carrier, SU-152, ML-20), theshermantank.com M3 gun data (FM data),
// miniatures.de AT weapon tables.
